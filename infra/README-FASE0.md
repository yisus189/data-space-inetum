# Fase 0 — Infra (Data Space) — Cómo probar localmente\n\nEstos archivos permiten levantar un entorno de desarrollo mínimo para la implementación del Data Space:\n- Keycloak (importa un realm dev)\n- MinIO (S3 compatible)\n- OpenMetadata (imagen dev)\n- Postgres (DB para la API)\n- API (Dockerfile listo para fases siguientes)\n\nRequisitos en tu máquina:\n- Docker Desktop (o Docker Engine + docker-compose)\n- Git\n\nPasos rápidos:\n1. Clona el repo y cámbiate a la rama feature/dataspace-full:\n   git clone https://github.com/yisus189/data-space-inetum.git\n   cd data-space-inetum\n   git checkout feature/dataspace-full\n\n2. Copia el .env ejemplo:\n   cp .env.local.example .env\n\n3. Levanta el stack:\n   docker-compose -f docker-compose.yml -f infra/docker-compose.override.yml up --build\n\n4. Verifica los servicios:\n   - Keycloak admin UI: http://localhost:8080  (usuario: kc-admin / changeMeAdmin123!)\n   - MinIO: http://localhost:9000  (usuario: minioadmin / minioadmin123)\n   - OpenMetadata (dev): http://localhost:8585  (si la imagen arranca)\n   - API (cuando esté implementada): http://localhost:8000/docs\n\n5. (Opcional) Crear bucket en MinIO:\n   ./infra/init_minio.sh\n\nNotas:\n- Credenciales incluidas son solo para desarrollo. Cambia las contraseñas si expones la máquina.\n- Si OpenMetadata no arranca por dependencias adicionales, la fase siguiente implementará soporte para mock y la integración real.
